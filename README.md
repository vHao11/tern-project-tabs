# Project Tabs for Tern

在 Tern 左侧按项目管理标签，查看 OMP 对话的运行状态，在原项目目录恢复历史会话。点击项目名可以折叠或展开，点击标签会回到原来的文件或终端。项目栏跟随当前标签，文件树可以单独开关。

## 安装与升级

在已安装 Tern 的终端运行下面的命令。项目标签栏使用 Tern 插件系统，历史会话功能还需要本机安装 OMP。1.7.0 已在 Windows 版 Tern 0.9.32 验证。

```sh
tern plugin install https://github.com/vHao11/tern-project-tabs
```

已有旧版时运行升级命令。

```sh
tern plugin install https://github.com/vHao11/tern-project-tabs --force
```

离线安装可从发布页下载 `project-tabs.zip`，解压后在含有 `plugin.toml` 的目录运行 `tern plugin install .`。升级本地安装时使用 `tern plugin install . --force`。[下载发布包](https://github.com/vHao11/tern-project-tabs/releases)

安装后按 **Alt+F9** 切换项目标签栏，也可以从 Files 标题栏的文件夹按钮打开。

## 使用

- **显示或隐藏**　按 `Alt+F9`。也可以点击项目栏底部的「隐藏项目栏」，再通过 Files 标题栏的文件夹按钮或命令面板里的「显示 / 隐藏项目标签栏」打开。重启 Tern 或切换会话时，同一窗口只保留一份项目栏。升级后，旧版留下的多余项目栏会自动移除。
- **切换标签**　点击项目名可展开或收起，括号里是该项目的标签数。点击其下的标签可直接切换，包括其他会话的标签。项目栏展开时顶部标签收起，隐藏时顶部标签恢复。
- **按项目找 OMP 历史会话**　点项目栏顶部的「OMP 历史会话」，历史卡片会浮在原标签上方。卡片内可以独立滚动，再点标题或卡片外的侧栏空白处即可收起。默认按对话的启动目录分组，项目旁的数字是该目录的历史会话数。点项目名展开或收起，最近更新的项目和对话排在前面。父目录和子目录各自成组，同名目录会显示上级路径，悬停可看完整路径。项目内可以翻页，也可以切到「按时间」跨项目查看。插件会记住上次选的视图。
- **恢复对话**　点历史记录，在原启动目录继续对话。当前窗口已经打开的对话会直接切回原标签。长标题会随侧栏宽度换行，收起再展开「OMP 历史会话」可刷新列表。
- **归档已打开的对话**　鼠标移到本机 OMP 标签，点「⋯」→「归档并关闭…」并确认。该标签内各分屏的 OMP 会话会从插件历史中移除，然后由 Tern 关闭标签。如果 Tern 另行提示是否关闭，取消那个提示会保留已打开的标签，已确认的归档仍然有效。只想关闭窗口并保留历史入口时，选「关闭标签」。
- **清理历史**　展开「OMP 历史会话」。在记录右侧点「⋯」→「从历史中移除…」可移除一条。在历史项目名旁点「⋯」→「清除此项目历史…」可清理该启动目录的所有页。卡片顶部的「⋯」提供「多选清除…」和「清空全部历史…」。多选支持跨页、跨项目勾选，点「清除所选」后核对数量并确认。直接从历史清理会保留已打开的标签。

归档和清除对「按项目」和「按时间」同时生效，重启后仍生效。清理项目或全部历史只作用于确认时列出的会话，之后的新对话照常显示。OMP 的原始聊天记录保留，仍可用 `omp --resume` 恢复对话。

- **在项目中新建对话**　将鼠标移到项目行，点击「⋯」→「新建对话」。Tern 会用当前配置的 Agent 打开并切到一个空白对话标签。起始目录取该分组的实际项目路径，改过显示名也一样。已折叠的项目会自动展开。若多个会话都打开了该项目，优先使用当前会话。
- **标签操作**　将鼠标移到标签行，点击右侧的「⋯」。选择「重命名标签」后输入标题并按 Enter，清空可恢复自动标题，Esc 取消编辑。选择「关闭标签」会关闭该标签及其分屏，需要确认时由 Tern 显示原生提示。
- **自定义项目名**　将鼠标移到项目行，点击「⋯」并选择「重命名项目」。别名按项目路径保存，重开 Tern 后仍然有效。清空后按 Enter 恢复目录名。
- **项目路径**　终端取当前工作目录，文件取所在目录。本地 Git 项目按最近的仓库根目录归组，普通目录按所在文件夹归组。遇到重名项目，会补上足以区分它们的上级目录。
- **指定项目范围**　在命令面板运行「添加项目根目录…」，输入一个目录即可把其子目录统一归组。多个自定义根目录嵌套时，采用最接近标签的那个。「移除自定义项目根目录…」可恢复自动分组。
- **调整宽度**　拖动项目栏与正文之间的分隔线。插件会记住窗口的显示状态、折叠状态和调整过的宽度。

## 运行状态

- **绿点**表示标签中有命令或 Agent 正在运行。默认常亮。在 Tern 命令面板搜索「设置运行绿点」，选择「呼吸」即可启用动画，再选「常亮（默认）」即可关闭。系统启用「减少动态效果」时，绿点保持常亮。
- **黄点**表示任务在本窗口的其他标签中完成。第一次切到该标签就会清除，使用侧栏或键盘切换都算查看。当前正在看的标签完成时直接回到空闲。一个标签有多个分屏时，仍有任务运行就继续显示绿点。
- **!** 表示 Tern 识别的 Agent 正等待确认或输入，优先于运行和完成状态。点进标签后仍会显示，直到 Agent 离开等待状态。
- **项目折叠时**，黄色数字表示已完成且尚未查看的标签数，每个标签只计一次。有标签等待确认时，项目行也显示 **!**。展开项目会保留未读标记。侧栏隐藏期间仍会记录新完成的任务，关闭窗口或重新加载插件后未读记录会重置。

终端命令依赖 shell 集成上报开始和结束。Tern 能识别的 Agent 使用回合状态。普通终端里常驻的 CLI 如果只报告整个进程的生命周期，指示灯也按整个进程更新。

项目栏使用 Tern 的原生分屏。如果标签已经上下分屏，重新进入时项目栏会放在左上窗格旁边。颜色跟随当前主题。

桌面上的标题会用满这一行。鼠标移到项目或标签上时，右端会浮出黑色渐变和白色「⋯」。状态点和折叠项目的未读数仍可见。点「⋯」打开菜单，点空白处可收起。项目栏只占窗口的一部分高度时，「⋯」会使用 Tern 的操作选择器，可点击选项或用方向键和 Enter 选择。
